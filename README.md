# 🌸 Bloom - 百合恋爱互动游戏

一段关于爱与成长的故事。

## 🎮 游戏简介

玩家作为女主角，搬到一个新城市，会遇到五位可能成为恋人的女性。每一次互动选择都可能带来不一样的剧情走向。

## 🎯 游戏特色

- ✨ **自定义主角**：名字、年龄、职业、MBTI 人格由你决定
- 🧠 **MBTI 测试**：10 道题测出你的人格类型，或自由选择
- 💕 **好感度系统**：每个选择都影响角色对你的好感
- 💾 **存档/读档**：6 个存档槽位，随时保存进度
- 🌸 **多结局**：根据选择和好感度，触发不同结局（HE/BE/NE）

## 🚀 快速开始

### 方法 1：直接打开
双击 `index.html` 文件即可在浏览器中运行。

### 方法 2：本地服务器（推荐）
```bash
# 使用 Python
cd bloom-love-game
python -m http.server 8000

# 或使用 Node.js
npx serve .
```

然后访问 `http://localhost:8000`

- **鼠标点击**：选择选项、继续对话
