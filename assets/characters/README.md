## 后续替换方案

使用 AI 绘画工具生成角色立绘：
- Midjourney
- Stable Diffusion
- DALL-E 3

提示词参考：
```
anime style character portrait, long hair, elegant, professional illustration, white background
```

### 方案 2：免费素材
推荐网站：
- https://itch.io/game-assets/free/tag-character
- https://opengameart.org/
- https://www.pngwing.com/

### 方案 3：约稿
在米画师等平台约稿画师。

## 图片规格

- 尺寸：300x500px（透明背景 PNG）
- 格式：PNG（支持透明）
- 命名：`linwanqing.png`, `xiayang.png`, `sujingyi.png`, `wenya.png`, `luxiao.png`
- 位置：`assets/characters/` 目录

## 背景图规格

- 尺寸：1920x1080px 或适配屏幕
- 格式：JPG/PNG
- 命名：按场景命名，如 `apartment.jpg`, `cafe.jpg`, `park.jpg`
- 位置：`assets/backgrounds/` 目录
